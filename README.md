# PIN&PAN — сборка первого этапа

Godot 4.7+. Открой `project.godot` в Godot и нажми F5.

## Что внутри (вертикальный срез)

**Интро (14 с, без слов)** — нить ткётся, рука Ткача тянет, вспышка, падение, имя. Пропуск с 3-й секунды.

**Главное меню** — ИГРАТЬ / ПРОДОЛЖИТЬ (только при сохранении) / НАСТРОЙКИ / ВЫХОД.
Фон: мастерская, луч света, силуэт станка, слои ткани, пыль, параллакс от курсора.
Герои живут idle-циклом 20 с (противофазное свечение → наклон Pan → дыхание нити);
после 45 с бездействия Pan трижды дёргает нить и оба поворачиваются.
Курсор — пружинная игла с хвостом (response 15, damping 0.30). Все UI-звуки синтезируются,
у Pin «деревянный» голос, у Pan — глиссандо. При двух геймпадах — два курсора,
ИГРАТЬ активируется совместным hover 300 мс.

**Пролог «Нить, которой не должно было быть»** — пробуждение → первое движение →
захват руки → разрыв → падение → посадка в льняном мире. Без текста, без Bind/Cut/Ignite.
Пропуск закрыт на время «захвата».

**Акт I** — Мир 1 «Льняные поля» (1.1–1.5: движение, совместные плиты, Bind-якорь,
узлы памяти, силуэт Корректора) и Мир 2 «Шерстяной лес» (Корректор с конусом обнаружения,
катушка-дрон с узловыми ловушками, погоня с Ignite). Фейл ≠ смерть: возврат на чекпоинт ≤3 с.

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Pin | A/D + W (прыжок) | стик 1 + Ⓐ |
| Pan | ←→/↑ (прыжок) | стик 2 + Ⓐ (или правый стик) |
| Bind (Pin) | E | Ⓧ |
| Cut / Ignite (Pan) | SHIFT или / | Ⓨ |
| Пауза | ESC | START |

Один игрок: оба героя на одной клавиатуре/геймпаде (левый+правый стик).
Два игрока: по геймпаду на героя.

## Настройки и доступность

Громкости (Master/Music/SFX/Атмосфера), натяжение нити (реально меняет физику),
яркость, тряска, палитры для протанопии/дейтеранопии/тританопии, символы ролей
(у Pin — треугольник, у Pan — капля), уменьшение движения, мягкая вспышка, высокий контраст.

## Архитектура

```
src/
  main.gd                  — корень: состояния, ввод, переходы, пауза
  core/                    — палитра, настройки, сейвы, синтез звука,
                             UI/игровые звуки, курсор, меню-логика, актёры
  screens/                 — intro, menu (+backdrop, hero), prologue, game, act_complete
  ui/                      — панель настроек, диалоги, пауза, курсор, фейд
tests/smoke.gd             — headless-прогон пути игрока:
                             godot --headless --script res://tests/smoke.gd
```

Ни одного внешнего ассета: вся графика процедурная, весь звук синтезируется на старте.
Сохранения: `user://savegame.cfg` (checkpoint, memoryNodes, endingFlags), настройки: `user://settings.cfg`.
